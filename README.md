# 📝 Task Manager App (React Native)

A sleek, professional, and lightweight Task Management application built with **React Native** and **Expo**. This app allows users to efficiently manage their daily tasks with a clean, modern UI and smooth interactions.

[![React Native](https://img.shields.io/badge/React_Native-v0.81-61DAFB?logo=react&logoColor=black)](https://reactnative.dev/)
[![Expo](https://img.shields.io/badge/Expo-v54-000020?logo=expo&logoColor=white)](https://expo.dev/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## ✨ Features

- **Add Tasks**: Quickly jot down your to-dos using the intuitive input field.
- **Dynamic List**: View all your tasks in a high-performance `FlatList`.
- **Mark Completion**: Easily toggle task completion with a satisfying visual feedback (checkmark & strikethrough).
- **Responsive Design**: Optimized for both iOS and Android using `KeyboardAvoidingView` and `SafeAreaView`.
- **Modern UI**: Soft shadows, rounded corners, and a clean color palette for a premium user experience.

---

## 🛠️ Tech Stack

- **Framework**: React Native (Functional Components)
- **Tooling**: Expo SDK 54
- **State Management**: React Hooks (`useState`)
- **Styling**: StyleSheet (Vanilla CSS-in-JS)
- **Icons**: Custom vector-style UI components

## 🚀 Getting Started

Follow these steps to get the project running locally on your machine.

### Prerequisites

- Node.js installed
- Expo Go app on your mobile device (for testing)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd YOUR_REPO_NAME
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npx expo start
   ```

4. **Run on your device**:
   - Scan the QR code using the **Expo Go** app (Android) or **Camera** app (iOS).
   - Press `w` to open in your web browser.

---

## 📦 Building the APK

This project is configured for **EAS Build**. To generate your own APK:

1. Install EAS CLI: `npm install -g eas-cli`
2. Log in: `eas login`
3. Build for Android: `eas build -p android --profile preview`
